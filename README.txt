NAFIS NIROB — PORTFOLIO v4
==========================

Run in Acode:
1. Extract this ZIP.
2. Open the extracted folder in Acode.
3. Open index.html and tap Preview / Run.
4. Keep the assets folder beside index.html.

THEME SELECTOR
- A permanent palette icon in the top bar opens the theme selector.
- Normal: clean minimal editorial theme.
- Zenitsu: uses the supplied Zenitsu video, thunder/gold palette and Bangers / Zen Kaku typography.
- Eren Yeager: uses the supplied Attack on Titan video, steel/crimson palette and Oswald / Barlow Condensed typography.
- Itachi: uses the supplied Itachi video, moonlight/scarlet palette and Cinzel / Playfair Display typography.
- Selecting a theme plays a short cinematic transition, changes the full page theme, icon accents, typography, cards, headings and video background.
- Selecting Normal returns to the original minimal theme.
- All three videos are bundled locally; no external video hosting is required.

FREE ASSETS
- Font Awesome Free 6.7.2 icon font via cdnjs CDN. Free icons only; no Pro assets.
- Google Fonts: DM Sans, Space Grotesk, Bangers, Zen Kaku Gothic New, Oswald, Barlow Condensed, Cinzel, Playfair Display, DM Mono (SIL Open Font License).
- Internet is needed for Google Fonts and the Font Awesome Free icon stylesheet. Fallback fonts are provided.

Existing features retained:
- Five original user images
- English / Bangla toggle
- Light / dark mode in Normal theme
- Smooth anchor scrolling, scroll progress, section reveals
- Responsive navigation, custom desktop cursor and interactive terminal
- Contact form opens the visitor's email app; it does not send automatically
- No backend or build step required.
